# 📊 Smart Habit Tracker (PWA)

A **Smart Habit Tracker** is a responsive **Progressive Web App (PWA)** that helps users build and maintain positive habits by tracking daily progress. It allows users to add custom habits, monitor completion percentages, and visualize sleep patterns through an interactive graph. The app works offline using Local Storage and can be installed on desktop or mobile devices.

## ✨ Features

- 📅 Monthly habit tracking (January–December)
- ➕ Add unlimited custom habits
- ✅ Mark daily habit completion
- 📊 Automatic habit completion percentage
- 🗓️ Create and manage a weekly timetable with days, times, and categories
- 🗑️ Delete habits anytime
- 😴 Sleep tracking with graphical visualization
- 💾 Local Storage support
- 📱 Responsive design
- 🌐 Progressive Web App (PWA)
- 📥 Installable on desktop and mobile
- ⚡ Offline support using Service Worker

## 🚀 Technologies Used

- HTML5
